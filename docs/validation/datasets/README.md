# Datasets

Dados de **entrada** versionados do Validation Sprint 0: a janela histórica selecionada, o inventário de fontes usadas, as amostras definidas por regra (objetos cross-source do Workstream E, pares de alternativas do Workstream F) e os catálogos de referência necessários para rotular.

Um dataset aqui é congelado e versionado (`dataset_version`). Se a entrada mudar, é uma nova versão — não uma edição da anterior. O `dataset_version` usado é citado em todo experiment log.

Formatos: CSV, JSON ou Markdown. Nenhum banco de dados é escolhido.

Schemas: [validation-sprint-0-protocol-v0.1.md §14](../validation-sprint-0-protocol-v0.1.md).
