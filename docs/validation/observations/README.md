# Observations

Registros **brutos** produzidos durante a execução dos experimentos: episódios, evidências, mudanças, oportunidades, briefings, feedback, resoluções de entidade, declarações de cognição, observações de custo e trials de auto-consistência.

Regras que governam este diretório:

- separar sempre **fato observado** de **inferência do revisor**; inferência vai em `notes`, nunca em campo de fato;
- preservar a ordem temporal real; nada é reordenado na reconstrução;
- listas de oportunidades geradas antes de abrir o futuro são **congeladas** e não podem ser editadas depois (anti-hindsight, protocolo §1);
- correções posteriores entram como nota separada marcada `post_hoc = true` e ficam fora das métricas;
- registrar sempre `n` e limitações.
