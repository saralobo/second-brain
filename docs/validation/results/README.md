# Results

Análises, **experiment logs** e decisões do Validation Sprint 0.

Cada experimento executado produz um log com os campos definidos em [validation-sprint-0-protocol-v0.1.md §15](../validation-sprint-0-protocol-v0.1.md): experiment ID, baseline e tag arquitetural, versão do protocolo, início/fim, versão do dataset, hipótese, critérios pré-definidos, desvios, resultado, interpretação, decisão e ADR relacionado.

Regras:

- `predefined_criteria` é copiado **antes** de iniciar; critério alterado durante a execução é `deviation`, e a decisão associada perde validade;
- resultado e interpretação são seções distintas;
- resultados negativos são registrados com o mesmo cuidado dos positivos;
- a Decision Matrix consolidada (protocolo §11) é preenchida aqui, ao fim do sprint, nunca antes;
- mudanças arquiteturais motivadas por evidência viram ADR em [../../decisions/](../../decisions/README.md), a partir de ADR-21 — a baseline congelada não é editada.
